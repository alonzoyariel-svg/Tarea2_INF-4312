# Ejercicios de INF-4312

Colección de ejercicios académicos de programación en C#, organizada por ejercicio. El repositorio conserva las entregas por separado para que cada práctica se pueda consultar y ejecutar de forma independiente.

## Contenido

Hay ejercicios numerados del 1 al 16, con algunas numeraciones ausentes en la carpeta actual. Cada carpeta contiene el proyecto correspondiente.

## Cómo abrirlos

1. Clona el repositorio.
2. Abre la carpeta del ejercicio que quieras revisar.
3. Abre su archivo de solución o proyecto en Visual Studio.
4. Restaura los paquetes si Visual Studio lo solicita y ejecuta ese proyecto.

## Tecnologías

- C#
- Visual Studio
- Windows Forms en los ejercicios que incluyen formularios
